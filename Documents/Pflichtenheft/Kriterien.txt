Muss-Kriterien:
-VR Umgebung
-Lecture browsing
-Lectures anschauen (anhalten, vorspulen etc.)
-Transcripts, Translations, Summaries (Textdokumente) lesen
-Dialog System anbindung für Fragenbeantwortung (mit VR Avatar)

---english version---
Mandatory Requirements:
-M1: Virtual Reality Environment
The system must run in a VR environment.

-M2:Lecture Browsing and Playback
Users must be able to browse available lectures.
Lectures must be watchable with basic controls (pause, skip, etc.).

-M3:Transcript, Translation, and Summary Access
Users must be able to read transcripts, translations, and summaries in text format.

-M4:LLM-based Dialogue System Integration
Users must be able to interact with a VR avatar.
The avatar must be connected to an LLM-based system capable of answering questions.
