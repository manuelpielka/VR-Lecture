Muss-Kriterien:
-VR Umgebung
-M1: Lecture browsing
-M2: Lectures anschauen (anhalten, vorspulen, untertitel, etc.)
-M3: Transcripts, Translations, Summaries (Textdokumente) lesen
-M4: Dialog System anbindung für Fragenbeantwortung (mit VR Avatar) (STT + TTS?)

---english version---
Mandatory Requirements:
-M1: Virtual Reality Environment
Implemented by: F1

The system must run in a VR environment.

-M2: Lecture Browsing and Playback
Implemented by: F2 F3

Users must be able to browse available lectures.
Lectures must be watchable with basic controls (pause, skip, subtitles, etc.).

-M3: Transcript, Translation, and Summary Access
Implemented by: F4

Users must be able to read transcripts, translations, and summaries in text format.

-M4: LLM-based Dialogue System Integration
Implemented by: F4

Users must be able to interact with a VR avatar.
The avatar must be connected to an LLM-based system capable of answering questions.


Wunsch-Kriterien:
-K1: Unterschiedliche Umgebungen
-K2: Multitasking (mehrere Lectures, bzw Textdokumente gleichzeitig anschauen und anordnen, größer/kleiner machen)
-K3: Funktion um im Programm Notizen zu schreiben? (wahrscheinlich unangenehm mit den Controllern)
-K4: Einstellbare Untertitelgröße
-K5: Kommentare zur Vorlesung hinzufügen (mit Zeitangabe, aber ohne Wiedergabeverknüpfung)
-K6: "Weiter ansehen“ Funktion (Wiedergabe an letzter Position fortsetzen)
-K7: Abspielgeschwindigkeit anpassen (1.25x, 1.5x, 1.75x, 2x, ...)
-K8: Kleines "Tutorial" wie Steuerung funktioniert?
-K9: Dark-/Light-Mode wird automatisch an das Umgebungslicht angepasst
-K10: Dunkelmodus / Umgebungslicht-Anpassung

---english version---
Optional Requirements:

-K1: Multiple VR Environments
Support for different virtual environments or backgrounds for viewing lectures.

-K2: Multitasking Capabilities
Allow users to open and arrange multiple lectures or documents at once, including resizing windows. Picture in Picture mode

-K3: Taking notes inside the VR app
Allow users to take notes while using VR.

-K4: Adjustable Subtitle Size
Allow users to increase or decrease the size of subtitles for better readability in VR.

-K5: Add Comments under the Lecture
Users can leave static comments while or after watching the video. The system records the time the comment was made, but comments are not linked to playback. 

-K6: Continue Watching Feature
The system remembers where the user left off in a lecture. When the user returns, it asks whether to resume playback from that point.

-K7: Playback speed
Users can adjust the playback speed of lecture videos

-K8: Control tutorial
Show the user how the basic controls work (Movement, opening menus, moving windows...) if they have not used VR before

-K9: Automatic mode switch
Automatic dark/light mode switch depending on ambient lighting.

-K10: Offline mode
Allow the user to download the video content as well the transcripts so that it can be viewed offline.


Abgrenzung-Kriterien:
-Keine Unterstützung für Nicht-VR-Modi (Web/Desktop/Mobil)
-Kein Benutzerkonto oder Rollensystem

---english version---
Excluded Requirements:

-A1: No Non-VR Modes (Web/Desktop/Mobile)
The system targets VR headsets only. No web, desktop, or mobile version will be developed.

-A2: No User Registration or Role Management
No account system, login process, or role-based permissions will be implemented.
Although the system does not include a user account module, personalized features are still supported.(Local personalization)
These features rely on local storage and are not synchronized across devices or user sessions.(no Cloud/social features)
