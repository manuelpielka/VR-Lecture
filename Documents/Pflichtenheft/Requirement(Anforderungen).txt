Requirement(Anforderungen)

Functional requirements: (Funktionale Anforderungen)

-F1: Movement in the VR Environment		Implements: M1
The user must be able to move around in the VR environment using their natural body movements.
Additionally they must be able to move longer distances that would not be walkable by teleportation.

-F2: Browsing Interface				Implements: M2
The UI needs to have an interface for browsing lectures.
This interface needs to include a search bar and controls for browsing through the folder architecture.

-F3: Lecture Player				Implements: M2
The UI needs to have an option for playing lectures.
This lecture player must include basic controls for pausing, skipping ahead and going back as well as enabling and disabling subtitles.
It should display how far in the lecture the user is using a bar.

-F4: Text Document Display			Implements: M3
The UI needs to have an option for displaying text documents related to a lecture, such as the full transcript, translations and summaries.

-F5: Virtual Avatar for the Dialogue System	Implements: M4
The system must include a virtual avatar that visually represents the AI dialogue system within the VR environment. The avatar must move its mouth in sync with generated speech.

-F6: Text Display for the Dialogue System	Implements: M4
The UI must display both user questions and avatar responses as on-screen text to support the dialogue system. 
This may appear as subtitles or in a dialogue box within the VR environment.

-F7: Switching Environments			Implements: K1

-FXX: Subtitle Size Adjustment Interface	Implements: K4
The UI must provide a settings interface that allows users to increase or decrease the subtitle size to improve readability in the VR environment.

-FXX: Continue Watching Feature		        Implements: K6
The system must remember the user's last watched position in a lecture and, upon return, the UI must prompt the user whether to resume playback from that point.
