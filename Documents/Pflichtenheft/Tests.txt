Tests

=====================================================================================================================================
-T1 Body Movement
Tests: M1, F1

State: The user has the software running and is wearing their VR-headset and controllers
Action: The user moves the controllers in their hands and their head
Reaction: The virtual representation of the users controllers and the camera position move accordingly

-------------------------------------------------------------------------------------------------------------------------------------
-T2 Teleportation Movement
Tests: M1, F1

State: The user has the software running and is wearing their VR-headset and controllers
Action: The user presses and holds the button associated with the teleportation functionality
Reaction: An outline appears where the user is pointing their controller, showing where they would teleport to

State: The user is holding the teleport button
Action: The user lets go of the teleport button
Reaction: The VR-Headset display fades to black, then starts displaying the environment from the position that was previously outlined

-------------------------------------------------------------------------------------------------------------------------------------
-T3 Opening A Lecture Browsing Window
Tests: M2, F2, K2, F16

State: The user has the main menu open
Action: The user presses the browse button in the main menu
Reaction: A lecture browsing interface window appears in the direction the user is looking

-------------------------------------------------------------------------------------------------------------------------------------
-T4 Lecture Browsing Interface
Tests: M2, F2, F3

State: The user has an open browsing interface window
Action: The user points at a folder in the windows representation of the folder architecture and pulls the trigger on the hand they are pointing at it with
Reaction: The browsing interface navigates into the folder and shows the subfolders and lectures in this folder
